## 📚 CSS Classes Reference

### Animation Classes
```
animate-spin         // Rotating spinner
animate-pulse        // Pulsing effect
animate-bounce       // Bouncing motion
animate-blob         // Custom blob animation
animate-shimmer      // Shimmer effect
animate-spin-slow    // Slow rotation
```

### Transform Classes
```
scale-110           // 110% size
hover:scale-125     // 125% on hover
-translate-y-4      // Move up 4 units
hover:translate-x-2 // Move right on hover
rotate-12           // 12 degree rotation
group-hover:rotate-90 // Rotate on group hover
```

### Backdrop Classes
```
backdrop-blur-sm    // Slight blur
backdrop-blur-md    // Medium blur
backdrop-blur-lg    // Strong blur
```

### Shadow Classes
```
shadow-lg           // Large shadow
shadow-2xl          // Extra large shadow
shadow-blue-400/60  // Colored shadow
hover:shadow-2xl    // Larger shadow on hover
```
