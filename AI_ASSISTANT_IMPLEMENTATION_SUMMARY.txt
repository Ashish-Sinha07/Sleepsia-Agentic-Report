================================================================================
  HOW TO USE
================================================================================

QUICK START (5 minutes):

1. Get Claude API Key:
   - Go to https://console.anthropic.com/
   - Create account and copy API key

2. Configure:
   - Add to .env: ANTHROPIC_API_KEY=sk_...

3. Install:
   - cd backend && pip install -r requirements.txt
   - cd ../dashboard && npm install

4. Run:
   - Terminal 1: cd backend && python -m uvicorn app.main:app --reload
   - Terminal 2: cd dashboard && npm run dev

5. Test:
   - Open http://localhost:5173/
   - Go to "AI Business Assistant"
   - Try a question: "Which platform is most profitable?"

For detailed setup, see: QUICKSTART_AI_ASSISTANT.md
