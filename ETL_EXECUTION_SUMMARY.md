## 12. Issues Encountered & Resolved

### Issue 1: Duplicate Dimension Records
**Problem:** Platforms and products already existed in database from schema seed data
**Root Cause:** Schema.sql includes INSERT IGNORE statements for master data
**Resolution:** Changed load mode to REPLACE for dimension tables
**Status:** ✓ RESOLVED

### Issue 2: Surrogate Key Conflicts
**Problem:** Excel data included return_id and cancellation_id as strings ('RET-0001', etc.)
**Root Cause:** Database expects auto-generated INT primary keys
**Resolution:** Excluded surrogate key columns from transformer, letting database auto-generate
**Status:** ✓ RESOLVED

### Issue 3: Unicode Encoding (Console Only)
**Problem:** Unicode characters (✓, ✗, ─) caused console output errors on Windows
**Root Cause:** Windows console encoding (cp1252) doesn't support Unicode
**Resolution:** Replaced with ASCII equivalents ([OK], [FAIL], -)
**Status:** ✓ RESOLVED (Data load not affected; logs properly recorded)
