## ⏱️ Animation Specifications

### Duration Breakdown
```
Fast Interactions:      150ms (click feedback)
Standard Transitions:   300ms (hover effects)
Smooth Animations:      400-500ms (entrance/lifting)
Continuous Movement:    7s (background blobs)
Shimmer Effect:         2s (repeating)
Rotation Effects:       500ms-3s (icon spinning)
```

### Easing Functions
```
Linear:              No acceleration (continuous animations)
Ease-Out:           Quick start, slow end (most interactions)
Cubic-Bezier(0.34, 1.56, 0.64, 1):  Bouncy entrance
```
