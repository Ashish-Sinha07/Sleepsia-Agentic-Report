```

├── From: Sleepsia Reports <your-email@gmail.com>
```

5-6. Product performance rankings and analysis
7. Advertising performance and ROI analysis

1. Cover sheet with summary metrics
2. Platform performance table
3. Product performance table
4. Advertising channels table
5. Profitability breakdown

## Customization Options

### Change Email Subject
Edit `automation/scheduler.py`, line ~54:
```python
subject=f"Sleepsia Daily Report - {date.today()}",
```
Change to:
```python
subject=f"[{date.today().strftime('%A')}] Business Report - {date.today()}",
```
Result: `[Wednesday] Business Report - 2026-08-23`

### Change Email Body
Edit `automation/scheduler.py`, lines ~55-67:
```python
body="""
Your custom message here.
You can add company-specific details.
"""
```

### Change Report Branding (in PDF/Excel)
Edit `automation/report_generator.py`, lines ~140-149:
```python
report_metadata = ReportMetadata(
    report_type=ReportType.PRODUCT_PLATFORM_DAILY,
    audit_date=report_date,
    organization="Sleepsia",  # ← Change this
    scope="all_channels",      # ← Or this
)
```
